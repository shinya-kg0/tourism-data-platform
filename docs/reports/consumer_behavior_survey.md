# 訪日外国人消費動向調査データ取得 作業レポート

作成日：2026年11月3日

## エグゼクティブサマリ

- **目的**：観光庁「訪日外国人消費動向調査」の直近10年分（2016〜2025年）を、Pythonで分析できる形にそろえること。
- **結論**：10年分の集計表を手元にそろえ、国籍・地域別の1人1回当たり旅行消費単価を年ごとに並べた表まで作成できた。
- **e-Stat APIだけでは足りなかった**：APIで取れるのは2014年〜2017年7–9月期まで（2019年3月の更新で止まっている）。2017年以降はExcelで補った。
- **Excelの取得を自動化した**：e-Statと観光庁サイトのExcelをダウンロードし、シートごとにCSVへ変換するスクリプトを作成。どの年も表の構成がほぼ同じなので、同じ表番号で年をまたいで比較できる。
- **主な結果**：1人1回当たり旅行消費単価（全体）は、2016年の約12.9万円から2025年には約21.0万円となり、約1.6倍に増えた。
- **使うときの注意**：2020・2021年はコロナで調査がほぼ中止され、四半期1期分しかない。2024年4–6月期から調査方法が変わっている。表3-1の値は報道発表の「1人当たり旅行支出」とは一致しない。

## 1. 背景と目的

訪日外国人の消費動向を長期的に分析するため、e-Stat（政府統計の総合窓口）から訪日外国人消費動向調査のデータを取得し、Jupyter Notebookで中身を確認できる環境を整えた。

## 3. 実施内容

### 3.1 環境構築

- プロジェクトの仮想環境（`.venv`、Python 3.9.6）にJupyterを導入した。
- e-Stat APIのキーは `.env`（`ESTAT_API_KEY`）から読み込む。コードにキーは書いていない。
- 使っているライブラリ：`jupyter` `ipykernel` `pandas` `requests` `python-dotenv` `xlrd` `openpyxl`

### 3.2 e-Stat APIでの取得（`consumer_behavior_survey.ipynb`）

- 統計表の一覧を取得し、キーワードで絞り込めるようにした。
- `get_stats_data(統計表ID)` で、ページ分けされたデータをまとめて取得する。コードは「国籍」「時間軸」などの名前に置き換え、扱いやすい縦持ちの表にする。

### 3.3 Excelの取得とCSV化（`fetch_excel_to_csv.py`）

- 2017〜2025年の集計表Excelをダウンロードし、シートごとにCSVへ変換する。
- 中身はExcelの見た目のまま保存する。表紙と利用上の注意のシートは除く。
- ダウンロード済みのファイルは取り直さない。年を指定して実行することもできる。
- 2017年だけ表番号が古い形式（「第6表」など）なので、表のタイトルで対応を確かめた上で、2018年以降と同じ「表3-1」形式の名前にそろえた。

```
.venv/bin/python fetch_excel_to_csv.py            # 全年
.venv/bin/python fetch_excel_to_csv.py 2024 2025  # 指定した年だけ
```

### 3.4 10年分の統合

2016年はAPI、2017年以降はCSVの表3-1（国籍･地域別 1人1回当たり旅行消費単価）から「全体」の行を取り出し、国籍×年の表にまとめた。

**読み取れること**

- コロナ前（2016〜2019年）の全体は13万円前後で横ばいだった。コロナ後（2023〜2025年）は19〜21万円まで上がっている。
- 欧米・オーストラリアの伸びが大きい。ドイツは2016年→2025年で約2.5倍、英国は約2.3倍になった。
- 中国は2022年に急上昇（試算値）した後、下がり続けている。2025年（約22.9万円）は2016年より2割高い程度まで戻った。
- 韓国は一貫して最も低く、2025年も10万円を下回っている。

## 5. 使うときの注意

1. **2020・2021年は1年分のデータではない。** コロナで調査が中止され、四半期1期分の値しかない。2021年の全体（516,321円）は5空港だけの試算値で、外れ値として扱う必要がある。
2. **2022年は試算値。** 1–9月期は一部の空港だけで調べている。
3. **2024年4–6月期から調査が新しくなった。** 名称も「インバウンド消費動向調査」に変わり、2024年より前と後を厳密に同じ条件で比べることはできない。
4. **報道発表の値とは一致しない。** 表3-1にはパッケージツアー代金の内訳が入っていない。報道発表の「1人当たり旅行支出」に合わせる場合は「参考1」（パッケージツアー参加費内訳含む）を使う。
5. **2016年だけ取得元が違う。** API（DB）とExcelでは表の形が違う。値は連続しているが、ほかの表も含めて完全に同じ定義かは確かめていない。
