# Looker Studio 構築手順

Looker Studio は Terraform で管理しないため、作り方をここに残す（仕様書 8 章、D-14）。
ダッシュボードが参照するのは BigQuery の `marts` データセットだけにする（D-15）。

## 1. データソースの作成

mart ごとに 1 つのデータソースを作る（D-09）。

1. [Looker Studio](https://lookerstudio.google.com/) で「作成」→「データソース」→「BigQuery」
2. 「マイプロジェクト」→ `tourism-data-platform` → データセット `marts` → テーブルを選ぶ
3. 右上の「接続」を押し、フィールドの型を下の表のとおりに設定する
4. データソース名は mart と同じ名前にする（例：`mart_kpi_yearly`）

### データの認証情報

仕様では、`marts` だけを読めるサービスアカウント `sa-looker` で読む（D-15）。

1. データソースの編集画面で「データの認証情報」→「サービス アカウント」を選ぶ
2. `sa-looker@tourism-data-platform.iam.gserviceaccount.com` を入力する
3. Looker Studio のサービスエージェントに、`sa-looker` のトークンを作る権限（`roles/iam.serviceAccountTokenCreator`）が必要
   - サービスエージェントのメールアドレスは、[こちらのページ](https://lookerstudio.google.com/c/serviceAgentHelp) に表示される
   - 権限は Terraform（`modules/iam`）で付ける

> **個人の Google アカウントで「サービス アカウント」が選べない場合**
> 一時的に「オーナーの認証情報」で接続し、この節に結果を記録する。このとき閲覧者は、オーナーの権限で `marts` を読むことになる（オーナーは raw も読めるが、データソースが指すのは marts のテーブルだけ）。

### フィールドの型（全 mart 共通）

列の名前の付け方をそろえているので、どの mart も同じ規則で設定する。

| フィールド | 型 | 表示形式 | 集計 |
|---|---|---|---|
| `year`、`month`、`*_sort_order` | 数値 | 桁区切りなし | なし |
| `year_date`、`month_date` | 日付と時刻 → 年 / 年月 | — | — |
| `*_guest_nights`、`visitors`、`*_respondents`、`purchasers`、`facilities_december` | 数値 | コンパクト数値（例：6.6億） | 合計 |
| `spend_per_*`、`estimated_foreign_spend` | 通貨（JPY） | 小数なし（推計消費額はコンパクト数値） | 平均（※） |
| `avg_nights` | 数値 | 小数 1 桁 | 平均（※） |
| `*_share`、`*_rate`、`*_yoy`、`share_of_year` | 数値 → パーセント | 小数 1 桁 | 平均（※） |
| `iso_3166_2` | 地域 → 国の下位区分（第 1 レベル） | — | — |
| `is_*` | ブール値 | — | — |
| そのほかの文字の列（国籍名・都道府県名・費目など） | テキスト | — | — |

※ 単価と率は足し合わせると意味がなくなる。グラフでは必ず 1 行 = 1 つの値になるディメンション（年 × 国籍など）で使い、
   スコアカードでは年と国籍を 1 つに絞ってから使う。

## 2. ページ 1：サマリ

### レイアウト

```
┌────────────────────────────────────────────────────────────┐
│ 観光統計ダッシュボード ― サマリ               [年: 2025 ▼] │
├──────────────┬──────────────┬──────────────┬───────────────┤
│ 延べ宿泊者数  │ うち外国人    │ 外国人比率    │ 日本人         │
│ 6.6億人泊     │ 1.8億人泊     │ 27.2%        │ 4.8億人泊      │
│ 前年比 +0.3%  │ 前年比 +9.4%  │              │ 前年比 −2.7%   │
├──────────────┴──────────────┴──────────────┴───────────────┤
│ 延べ宿泊者数の推移（日本人・外国人の積み上げ棒）             │
├──────────────────────────────┬─────────────────────────────┤
│ 外国人比率の推移（折れ線）      │ 年別の表                     │
├──────────────────────────────┴─────────────────────────────┤
│ ※2020〜2022 年はコロナの影響で急減。出典：観光庁「宿泊旅行統計調査」 │
└────────────────────────────────────────────────────────────┘
```

### 作り方

| 部品 | グラフの種類 | 設定 |
|---|---|---|
| 年の選択 | プルダウンリスト | コントロール項目 `year`、単一選択、既定値は最新の年。**スコアカード 4 つだけ**に効くよう、スコアカードとまとめてグループ化する |
| 延べ宿泊者数 | スコアカード | 指標 `total_guest_nights`。下に `total_guest_nights_yoy` のスコアカードを小さく置く |
| うち外国人 | スコアカード | 指標 `foreign_guest_nights`、`foreign_guest_nights_yoy` |
| 外国人比率 | スコアカード | 指標 `foreign_share` |
| 日本人 | スコアカード | 指標 `japanese_guest_nights`、`japanese_guest_nights_yoy` |
| 客室稼働率・消費単価 | スコアカード（2 行目に追加） | 指標 `room_occupancy_rate`、`spend_per_trip`（`spend_per_trip_yoy` を下に）、`avg_nights` |
| 延べ宿泊者数の推移 | 積み上げ縦棒グラフ | ディメンション `year_date`、指標 `japanese_guest_nights`・`foreign_guest_nights`、並べ替え `year_date` 昇順 |
| 外国人比率の推移 | 折れ線グラフ | ディメンション `year_date`、指標 `foreign_share` |
| 年別の表 | 表 | ディメンション `year`、指標は全体・日本人・外国人・外国人比率・前年比。`is_covid_period` が true の行に背景色を付ける（条件付き書式） |
| 注記 | テキスト | コロナの影響と出典（下の「データについて」と同じ文言） |

## 3. ページ 2：国籍分析

データソース：`mart_nationality_yearly`、`mart_nationality_spend_category_yearly`

### レイアウト

```
┌────────────────────────────────────────────────────────────┐
│ 国籍分析                          [年: 2025 ▼] [地域区分 ▼] │
├──────────────────────────────┬─────────────────────────────┤
│ 宿泊者数 × 消費単価（散布図）   │ 費目別の 1 人当たり支出        │
│ 円の大きさ＝平均泊数            │（国籍ごとの積み上げ横棒）      │
├──────────────────────────────┴─────────────────────────────┤
│ 国籍別の推移（折れ線。宿泊者数 / 消費単価を切り替え）         │
├────────────────────────────────────────────────────────────┤
│ ※宿泊者数は従業者数 10 人以上の施設。2021 年は国籍別の値がない │
└────────────────────────────────────────────────────────────┘
```

### 作り方

| 部品 | グラフの種類 | データソース | 設定 |
|---|---|---|---|
| 年の選択 | プルダウンリスト | `mart_nationality_yearly` | `year`、単一選択、既定値は最新の年。散布図と積み上げ棒に効くようグループ化する |
| 地域区分 | プルダウンリスト | `mart_nationality_yearly` | `region`、複数選択 |
| 散布図 | バブルチャート | `mart_nationality_yearly` | ディメンション `nationality_name`、X 軸 `foreign_guest_nights`、Y 軸 `spend_per_trip`、バブルのサイズ `avg_nights`、色 `region`。フィルタ `is_total = false` |
| 費目別の支出 | 積み上げ横棒グラフ | `mart_nationality_spend_category_yearly` | ディメンション `nationality_name`、内訳ディメンション `spend_category`、指標 `spend_per_visitor`。フィルタ `spend_stage = 日本滞在中`。並べ替え `nationality_sort_order` 昇順 |
| 国籍別の推移 | 折れ線グラフ | `mart_nationality_yearly` | ディメンション `year_date`、内訳ディメンション `nationality_name`、指標 `foreign_guest_nights`（オプションの指標に `spend_per_trip`・`avg_nights`）。フィルタ `is_total = false` |
| 注記 | テキスト | — | 宿泊者数は参考第1表（従業者数 10 人以上の施設）であること、2020・2021 年は四半期 1 期分の値（`consumption_period_label`）であること |

- 散布図は国籍ごとの差が大きいので、X 軸を対数目盛りにすると見やすい。
- 「その他」は 2026 年から消費動向調査の範囲が変わる（メキシコ・北欧・中東が別になる）ため、年をまたいで比べない。

## 4. ページ 3：地域分析

データソース：`mart_prefecture_yearly`、`mart_prefecture_nationality_yearly`

### レイアウト

```
┌────────────────────────────────────────────────────────────┐
│ 地域分析                [年: 2025 ▼] [指標: 外国人延べ宿泊者数 ▼] │
├──────────────────────────────┬─────────────────────────────┤
│ 都道府県の色分け地図            │ 推計消費額の上位（横棒）       │
├──────────────────────────────┴─────────────────────────────┤
│ 都道府県 × 国籍のヒートマップ（国籍の構成比）                  │
├────────────────────────────────────────────────────────────┤
│ ※推計消費額＝外国人延べ宿泊者数×1泊当たり消費単価。回答数30未満は参考値 │
└────────────────────────────────────────────────────────────┘
```

### 作り方

| 部品 | グラフの種類 | データソース | 設定 |
|---|---|---|---|
| 年の選択 | プルダウンリスト | `mart_prefecture_yearly` | `year`、単一選択、既定値は最新の年。ページ全体に効かせる |
| 色分け地図 | 塗り分けマップ（Google マップ） | `mart_prefecture_yearly` | 地域 `iso_3166_2`、色の指標 `foreign_guest_nights`（オプションの指標に `foreign_share`・`visit_rate`・`spend_per_night`・`room_occupancy_rate`）。ツールチップ `pref_name` |
| 推計消費額の上位 | 横棒グラフ | `mart_prefecture_yearly` | ディメンション `pref_name`、指標 `estimated_foreign_spend`、降順・上位 15 件。`is_low_sample = true` の行は色を変える（条件付き書式）|
| ヒートマップ | ピボットテーブル（ヒートマップ） | `mart_prefecture_nationality_yearly` | 行 `pref_name`、列 `nationality_name`、指標 `nationality_share_in_prefecture`。フィルタ `is_total = false`。列の並べ替え `nationality_sort_order` |
| 注記 | テキスト | — | 推計消費額の計算方法と、回答数が少ない県は値がぶれること。表3-4 がない年（2017 年以前、2020〜2022 年）は消費単価と推計消費額が空になること |

- 地図は「国の下位区分（第 1 レベル）」の ISO 3166-2 コード（`JP-13` など）で塗り分ける。都道府県名だと一致しない県が出る。
- ヒートマップに訪問率を出す場合は、指標を `visit_rate` に替える（消費動向調査の回答者が対象で、宿泊者数とは別の調査）。

## 5. ページ 6：データについて

テキストで次を載せる（仕様書 8.1）。

| 見出し | 載せる内容 |
|---|---|
| 出典 | 観光庁「宿泊旅行統計調査」（年確定値、2016 年〜）、「訪日外国人消費動向調査」（暦年・四半期、2016 年〜）。2024 年 4–6 月期からは「インバウンド消費動向調査」 |
| 欠けている期間 | 2020 年は 1–3 月期、2021 年は 10–12 月期だけ（コロナで調査が中止）。2021・2022 年は一部の空港での試算値で、2021 年は国籍別の値がない。地域調査（訪問地別の消費単価・訪問率）は 2020 年 4–6 月期〜2023 年 1–3 月期に中止 |
| 調査の変更 | 2024 年 4–6 月期から新調査。2026 年から国籍・地域が 24 区分（メキシコ・北欧・中東を追加）になり、「その他」の範囲が変わった。2017 年以前は費目の名前と集計の対象が少し違う |
| 宿泊者数の範囲 | 国籍別の宿泊者数は、従業者数 10 人以上の施設だけの集計（参考第1表）。サマリと地域分析の外国人延べ宿泊者数は全施設（第2表） |
| 推計の方法 | 都道府県の推計消費額 ＝ 外国人延べ宿泊者数 × 1 人 1 泊当たり旅行消費単価。宿泊を伴う消費の目安で、日帰りは含まない。回答数が 30 未満の県・国籍は値がぶれやすい |
| そのほか | 公表値は 10 人泊単位で丸められているため、合計が一致しないことがある。「日本人」は全体から外国人を引いて計算している。1 人 1 回当たり旅行消費単価はパッケージツアー参加費の内訳を含まないため、報道発表の値とは一致しない |

## 6. 共有設定

- 「共有」→「リンクを知っている全員が閲覧可」
- 「ファイル」→「レポートの設定」→ データの更新頻度（キャッシュ）を 12 時間にする
